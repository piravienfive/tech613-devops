
# Cloud Computing Notes

## What is Cloud Computing?

Cloud computing means using servers, storage and software over the internet instead of buying and managing your own equipment.

Example: Google Drive lets you store files online instead of only on your computer.

## On-Premises vs Cloud

- **On-Premises (On-Prem):** A business owns and manages its own servers and equipment.
- **Cloud:** A business rents computing services from a provider like AWS, Azure or Google Cloud.

Simple example:
- On-Prem = Owning a house.
- Cloud = Renting a house.

## 4 Cloud Deployment Models

1. **Public Cloud:** Cloud services available to many customers. Example: AWS.
2. **Private Cloud:** Cloud infrastructure dedicated to one organisation.
3. **Hybrid Cloud:** A mix of private infrastructure and public cloud.
4. **Community Cloud:** Cloud infrastructure shared by organisations with similar needs.

**Simple:** Public cloud is usually the easiest to set up.

**Complex:** Hybrid cloud can be harder because different systems must work together.

## 3 Cloud Service Types

### IaaS - Infrastructure as a Service

You rent servers, storage and networking but manage your own operating system and applications.

Example: Amazon EC2.

### PaaS - Platform as a Service

You build and run applications while the provider manages the underlying servers and operating systems.

Example: Google App Engine or Azure App Service.

### SaaS - Software as a Service

You use ready-made software over the internet.

Example: Gmail, Microsoft 365 or Dropbox.

## Who Manages What?

| Responsibility | IaaS | PaaS | SaaS |
|---|---|---|---|
| Applications | You | You | Provider |
| Data | You | You | Shared |
| Operating system | You | Provider | Provider |
| Physical servers | Provider | Provider | Provider |
| Physical networking | Provider | Provider | Provider |

Easy way to remember:
- **IaaS:** Rent the equipment.
- **PaaS:** Rent a platform to build apps.
- **SaaS:** Use a finished app.

## Advantages of Cloud Computing

- Lower starting costs.
- Easy to increase or decrease resources.
- Access services from almost anywhere.
- Faster to set up new systems.
- Less physical equipment to manage.

## Disadvantages of Cloud Computing

- Costs can increase unexpectedly.
- Often depends on internet access.
- Providers can experience outages.
- Moving between providers can be difficult.
- Businesses still need to manage security and protect their data.

## CapEx vs OpEx

**CapEx (Capital Expenditure):** Paying upfront to buy something.

Example: Buying servers for £20,000.

**OpEx (Operating Expenditure):** Paying ongoing costs to use something.

Example: Paying £300 per month for cloud services.

Many businesses prefer OpEx because:
- Less money is needed upfront.
- Spending can change depending on demand.
- It is easier to start small.

However, some businesses prefer CapEx for long-term, predictable workloads.

## Is Cloud Always Cheaper?

No.

Cloud can be cheaper when demand changes or a business wants to avoid buying expensive equipment.

On-Prem can be cheaper when a business has steady workloads over many years.

Example: An online shop can use extra cloud resources during Christmas sales and reduce them afterwards.

## SLA, SLO and SLI

**SLA (Service Level Agreement):** A formal agreement about the service a provider promises.

**SLO (Service Level Objective):** A target for how well a service should perform.

**SLI (Service Level Indicator):** A measurement of how well the service actually performs.

Example:
- SLA = Provider promises 99.9% monthly availability.
- SLO = Team aims for 99.95% availability.
- SLI = Actual availability measured at 99.97%.

Easy way to remember:
- **SLA = Promise**
- **SLO = Target**
- **SLI = Measurement**

## Cloud Market Share

The Big Three cloud infrastructure providers are:

1. Amazon Web Services (AWS)
2. Microsoft Azure
3. Google Cloud

Approximate global cloud infrastructure market share in Q4 2025:

- AWS: 28%
- Microsoft: 21%
- Google Cloud: 15%

These figures change over time.

## What Are the Big Three Known For?

### AWS (Amazon Web Services)

- Large range of cloud services.
- Widely used by startups and large companies.
- Good for learning general cloud computing.

### Microsoft Azure

- Works well with Microsoft products.
- Popular with businesses already using Microsoft software.
- Good for organisations using Windows and Microsoft 365.

### Google Cloud

- Strong in data analytics and artificial intelligence (AI).
- Known for tools such as BigQuery.
- Good for businesses working with large amounts of data.

## Cloud Certification Paths

### AWS

1. AWS Certified Cloud Practitioner (Beginner)
2. AWS Certified Solutions Architect - Associate (Intermediate)
3. AWS Certified Solutions Architect - Professional (Advanced)

### Microsoft Azure

1. Azure Fundamentals - AZ-900 (Beginner)
2. Azure Administrator Associate - AZ-104 (Intermediate)
3. Azure Solutions Architect Expert - AZ-305 (Advanced, with prerequisite)

### Google Cloud

1. Cloud Digital Leader (Beginner)
2. Associate Cloud Engineer (Intermediate)
3. Professional Cloud Architect (Advanced)

These are example learning paths.

## Which Cloud Path Would I Choose?

I would choose **AWS**.

Reasons:
- It is widely used.
- It offers many services to learn.
- There are plenty of beginner-friendly resources.
- AWS certifications can help demonstrate cloud knowledge.

I would start with AWS Cloud Practitioner and then learn services like EC2, S3 and Lambda.
