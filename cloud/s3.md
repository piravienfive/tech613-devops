# AWS S3 CLI Commands

I used AWS CLI on my Ubuntu EC2 instance to manage S3 buckets and files.

## Commands

### 1. List buckets
```bash
aws s3 ls
```

### 2. Create a bucket
```bash
aws s3 mb s3://my-bucket
```

### 3. List files in a bucket
```bash
aws s3 ls s3://my-bucket
```

### 4. Upload a file
```bash
aws s3 cp file.txt s3://my-bucket/
```

### 5. Download a file
```bash
aws s3 cp s3://my-bucket/file.txt .
```

### 6. Copy a whole folder
```bash
aws s3 cp my-folder/ s3://my-bucket/ --recursive
```

### 7. Delete a file
```bash
aws s3 rm s3://my-bucket/file.txt
```

### 8. Delete all files
```bash
aws s3 rm s3://my-bucket/ --recursive
```

### 9. Delete an empty bucket
```bash
aws s3 rb s3://my-bucket
```

### 10. Delete a bucket and its files
```bash
aws s3 rb s3://my-bucket --force
```

## What I Learned

- `ls` = List
- `mb` = Make bucket
- `cp` = Copy
- `rm` = Remove files
- `rb` = Remove bucket
- `--recursive` = Include all files and subfolders
- `--force` = Delete bucket contents before removing the bucket (with `rb`)




# AWS S3 Boto3 Task

## Aim

Use Python Boto3 on an Ubuntu EC2 instance to create and manage AWS S3 buckets and files.

## 1. Install Dependencies

Update Ubuntu and install Python dependencies:

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv unzip curl
```

Check AWS CLI:

```bash
aws --version
```

If AWS CLI is not installed, install it:

```bash
curl -fsSL https://awscli.amazonaws.com/v2/install.sh | bash
```

## 2. AWS Authentication

Configure AWS CLI:

```bash
aws configure
```

Enter your AWS access key, secret key, region and output format.

Check authentication:

```bash
aws sts get-caller-identity
```

Never upload AWS credentials to GitHub.

## 3. Install Boto3

Create a project folder:

```bash
mkdir ~/s3-boto3-task
cd ~/s3-boto3-task
```

Create and activate a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install Boto3:

```bash
pip install boto3
```

## 4. Previous AWS CLI Commands

- `aws s3 ls` - List buckets
- `aws s3 mb` - Create bucket
- `aws s3 cp` - Copy files
- `aws s3 rm` - Delete files
- `aws s3 rb` - Delete bucket
- `--recursive` - Include all files and folders
- `--force` - Delete bucket contents when using `rb`

## 5. Boto3 Python Scripts

Replace `tech613-yourfirstname-test-boto3` with your own unique bucket name in every script.

The examples use the AWS region `eu-west-2`.

### Script 1 - List Buckets

File: `list_buckets.py`

```python
import boto3

s3 = boto3.client("s3")

response = s3.list_buckets()

for bucket in response["Buckets"]:
    print(bucket["Name"])
```

Run:

```bash
python3 list_buckets.py
```

This lists all my S3 buckets.

### Script 2 - Create Bucket

File: `create_bucket.py`

```python
import boto3

s3 = boto3.client("s3", region_name="eu-west-2")

s3.create_bucket(
    Bucket="tech613-yourfirstname-test-boto3",
    CreateBucketConfiguration={"LocationConstraint": "eu-west-2"}
)

print("Bucket created")
```

Run:

```bash
python3 create_bucket.py
```

This creates a new S3 bucket.

### Script 3 - Upload File

First, create a test file:

```bash
echo "Hello from EC2" > test.txt
```

File: `upload_file.py`

```python
import boto3

s3 = boto3.client("s3")

s3.upload_file(
    "test.txt",
    "tech613-yourfirstname-test-boto3",
    "test.txt"
)

print("File uploaded")
```

Run:

```bash
python3 upload_file.py
```

This uploads `test.txt` to my S3 bucket.

### Script 4 - Download File

File: `download_file.py`

```python
import boto3

s3 = boto3.client("s3")

s3.download_file(
    "tech613-yourfirstname-test-boto3",
    "test.txt",
    "downloaded.txt"
)

print("File downloaded")
```

Run:

```bash
python3 download_file.py
```

This downloads the file from S3 and saves it as `downloaded.txt`.

Check:

```bash
cat downloaded.txt
```

### Script 5 - Delete File

File: `delete_file.py`

```python
import boto3

s3 = boto3.client("s3")

s3.delete_object(
    Bucket="tech613-yourfirstname-test-boto3",
    Key="test.txt"
)

print("File deleted")
```

Run:

```bash
python3 delete_file.py
```

This deletes `test.txt` from my S3 bucket.

### Script 6 - Delete Bucket

File: `delete_bucket.py`

```python
import boto3

s3 = boto3.client("s3")

s3.delete_bucket(
    Bucket="tech613-yourfirstname-test-boto3"
)

print("Bucket deleted")
```

Run:

```bash
python3 delete_bucket.py
```

This deletes my empty S3 bucket.

The bucket must be empty before deleting it.

## 7. What I Learned

- Boto3 is a Python library for AWS.
- `boto3.client("s3")` connects to the S3 service.
- `list_buckets()` lists buckets.
- `create_bucket()` creates a bucket.
- `upload_file()` uploads files.
- `download_file()` downloads files.
- `delete_object()` deletes files.
- `delete_bucket()` deletes a bucket.
